# Makgregor Alves Altê · Developer Portfolio

Software engineering, applied AI, and creative computing projects by Makgregor Alves Altê, a Computer Engineering student at the Federal University of Rio Grande (FURG), Brazil.

[View portfolio](https://makgregor-alte.github.io/international-developer-portfolio/) · [LinkedIn](https://www.linkedin.com/in/makgregor-alt%C3%AA/) · [GitHub](https://github.com/Makgregor-Alte)

## Selected projects

- **[Mosaikos](https://github.com/Makgregor-Alte/mosaikos-releases)**. Desktop editor for creating mathematical mosaics through symmetry, developed in Python and Pygame at FURG.
- **[Federal Servant Search](https://github.com/Makgregor-Alte/federal-servant-search)**. Team project for querying Brazilian federal public service records with Flask, PostgreSQL, and Docker Compose.
- **Language & Healthcare**. Research on extracting diagnoses, medications, and treatments from Portuguese clinical records.
- **Inventory Management**. Desktop application for product registration, stock movements, and batch tracking, built with Java, Swing, and SQLite.
- **FreakyHires**. REST API for tracking job applications, built with FastAPI and Pydantic.

The portfolio presents project case studies and a résumé in English and Portuguese. It is built with HTML, CSS, and JavaScript and designed for mobile and desktop browsers.
